# Domínio: a11y (WCAG 2.2 AA)

- [A11Y] Controle interativo é `button` ou `a` nativo. Nunca `div` ou `span` clicável. — origem: review-a11y/semantica
- [A11Y] Fluxo principal funciona só com teclado, do início ao fim. — origem: review-a11y/teclado
- [A11Y] Todo controle tem nome acessível; botão só com ícone leva `aria-label`. — origem: review-a11y/nome-acessivel
- [A11Y] Modal move o foco para dentro, prende o foco, fecha com Escape e devolve o foco ao gatilho. — origem: review-a11y/foco-em-modal
- [A11Y] Nunca `outline: none` sem um indicador de foco visível no lugar. — origem: review-a11y/foco-visivel
- [A11Y] Erro de formulário fica associado ao campo (`aria-describedby`) e é anunciado. — origem: review-a11y/formulario
- [A11Y] Contraste de texto de pelo menos 4.5:1 (3:1 para texto grande e UI). — origem: review-a11y/contraste
- [A11Y] Troca de rota em SPA move o foco ou anuncia o novo título. — origem: review-a11y/rota
- [A11Y] `aria-hidden` nunca em container com elemento focável. — origem: review-a11y/aria-hidden
- [A11Y] Alvo de toque com pelo menos 24×24 px; 44 px no mobile. — origem: review-a11y/target-size
- [A11Y] Vídeo novo do fluxo principal tem legenda. Nada pisca mais de 3 vezes por segundo. — origem: review-a11y/midia
- [A11Y] Defeito de componente de design system externo vira issue no repo do DS; use as props de a11y que ele oferece, sem override local. — origem: review-a11y/defeito-no-design-system
